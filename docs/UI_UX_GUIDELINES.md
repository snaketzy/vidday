# UI / UX 规范

本规范用于新改动及相关回归，不表示现有页面已全部达标。参见[产品需求与范围](../docs/PROJECT.md)及[任务看板](../tasks/TASK_BOARD.md)。

| 场景 | 实现要求 | 验收方法 |
|---|---|---|
| 主题与组件 | Web 优先复用 `components/ui` 和 `globals.css` 的语义色；Flutter 优先复用 `ThemeData` 和 `widgets.dart`。区分焦点、选中和禁用，不只靠颜色表达。 | 同屏检查默认、焦点、选中、禁用状态；普通文字对比度目标至少 4.5:1。 |
| 内容列表与详情 | 区分加载、成功但为空、网络失败与资源不存在；失败提供重试入口。图片缺失时保留片名，不让卡片跳动或丢失可操作区域。 | 用正常、空数组、404、500 和慢响应样例分别验证；切换作品不能短暂显示上一部作品数据。 |
| Web / Electron | 键盘可见焦点；交互元素可用 Tab 和 Enter/Space 激活；弹窗 Escape 关闭并返回触发器。没有桌面桥接时不展示不可用的桌面动作。 | 仅用键盘完成浏览、打开详情和返回；窄屏到桌面宽屏验证无页面级横向溢出。 |
| Android 手机 / 平板 | 核心控件保留触摸反馈和语义标签，触摸目标至少 48 dp；旋转和系统返回不丢失必要状态。 | 在手机和平板尺寸分别验证点按、横竖屏和返回；控件不被系统栏遮挡。 |
| Android TV | D-pad 能进入导航、卡片、详情与播放操作；确认只触发一次，隐藏页签不抢焦点，返回尽量恢复到原控件。焦点变化不得靠悬停或触摸。 | 用真遥控器完成首页 → 详情 → 播放 → 返回，并记录焦点轨迹；另测触屏不回归。 |
| 播放 | 区分首帧前、缓冲、暂停、出错；轨道菜单标出当前项和关闭/自动选项。字幕或 QoE 错误不应阻断画面。仅显示终端支持的全屏和 PiP 操作。 | 固定样本验证弱网、切轨、字幕关闭、退播重进及支持时的 PiP；不支持能力不算失败，但要记录。 |

截图和操作记录用合成数据，不含真实设备 ID、帐号、带签名 URL 或订阅信息。交付时注明浏览器或设备、输入方式、窗口尺寸、媒体样本和未覆盖场景。

## 影片详情页：Infuse 参考与验收

视觉参考：用户提供的 Infuse《Season of the Witch》（主按钮为 `Play`）和《The Peacemaker》（主按钮为 `Resume 00:13:59`）影片详情截图。以信息层级、分区和操作入口为对齐目标；参考设备与版本未确认，不将截图尺寸或图标样式作为跨端像素要求。此节只覆盖电影详情和进入/退出播放的交接，不定义剧集选集或播放页控制条。

| 编号 | 验收项 | 通过标准 |
|---|---|---|
| DETAIL-01 | 顶栏与主视觉 | 顶栏有返回和片名；可用的收藏与更多操作置于右侧。下方用全宽背景图和底部渐变衔接深色内容区；标题图缺失时用文字片名，背景缺失时保留可读的纯色底。 |
| DETAIL-02 | 播放区与影片信息 | 宽屏按参考图分两列：左侧片名、显著的播放按钮及次级动作，右侧评分、年份、分级、类型和简介；窄屏按同一信息层级纵向排布。简介截断时提供「更多」，展开可读全文；缺失元数据不显示空徽章或虚构评分。 |
| DETAIL-03 | 演职员与观看区 | 演职员横向列表在主视觉下方；人物卡显示姓名和可用的角色或职务，无头像仍可识别。参考图的 `Watching` 区在演职员之后；仅当本端有真实观看数据时才显示，不用重复海报凑数，也不以推荐内容冒充观看记录。 |
| DETAIL-04 | 播放与返回 | 有合法片源时，一次确认或点击只进入一次播放；有可用续播进度且本端支持时显示「继续观看」，否则显示「播放」。无源时给出明确提示，不以演示视频代替影片。返回详情后保留滚动位置，键盘和 TV 遥控器恢复到触发控件或最近可用控件。 |
| DETAIL-05 | 退化与跨端验收 | 用完整数据、缺背景或头像、简介过长、无源四类夹具核对宽屏和窄屏；键盘与遥控器分别走「详情 → 播放 → 返回」。提交首屏与演职员区截图，以及播放返回后的滚动或焦点记录。 |
| DETAIL-06 | 有可续播记录 | 复用主播放按钮的位置，显示「继续观看 00:13:59」一类文案。进度条位于主视觉与演职员之间，左起填充已看比例，在进度位置附近标已看时长，右侧标总时长。按钮、进度条与实际续播位置使用当前影片的同一条有效记录。详情页进度条先按只读指示验收，不从静态截图推断可拖动。 |
| DETAIL-07 | 有无进度的切换 | 用 `position=839`、`duration=7433`（秒）的样例验证主按钮、约 11% 的进度、`13:59` 与 `2:03:53`，点击后从已保存位置附近续播。无记录、记录不可续播或端侧未接入观看进度时，不显示续播时间或进度条；无有效片源时仍遵循 `DETAIL-04`。在支持保存进度的端上，退播回详情后确认显示更新后的记录。 |

《The Peacemaker》的「每日精选」是独立内容区，不等同于当前影片的观看进度或 `Watching`。截图中的 4K、DV 以及底部 HEVC、DTS 等媒体规格，仅在有可信数据时展示，不从片名或文件名猜测。含义未确认的快捷图标、独立评分来源及底部文件名不作为必做项。若需要新增公开字段或改变播放行为，先走变更审批。

## 播放交互：Infuse 参考与验收

参考：用户提供的 `Jietu20261123-205203-HD.mp4`，约 23 秒，内容为 macOS 上使用鼠标操作 Infuse 播放《The Peacemaker》。下文用录屏时间定位证据，并将桌面视觉参考与 Vidday 跨端回归要求区分开。原录屏及抽帧不入库。

| 编号 | 验收项 | 检查方法 |
|---|---|---|
| PLAY-01 | 进入、暂停与返回 | 从详情点击一次「播放」或「继续观看」，只进入一次，在 Vidday 不自动触发系统或浏览器全屏。播放与暂停切换时图标反映真实状态。普通退播回到同一详情，保留滚动和可用焦点；支持保存进度的端在返回后同步刷新续播按钮和进度条。录屏约 `00:18–00:21` 可见暂停、退播，详情更新为 `Resume 00:53:40`。 |
| PLAY-02 | 拖动预览与提交 | 录屏约 `00:03–00:08`：拖动进度时滑块、目标时间与上方缩略图跟随指针，主画面不随每个移动位置跳转；释放后关闭预览并跳转到目标。桌面用有预览图的样本验收；无图时保留目标时间，仍可跳转。Android 保留拖动时间气泡。验证拖到两端时预览不出屏，并区分拖动中的目标时间与提交后的实际播放时间。 |
| PLAY-03 | 设置菜单与轨道 | 录屏约 `00:09–00:16`：齿轮打开分组菜单，字幕和音轨展开独立子菜单；当前项有勾选，字幕有「关闭／无」。验收分开覆盖移动指针展开、用键盘可达，以及实际选择后生效；录屏展示了菜单浏览，未确认切换结果。画质自动选项按 Vidday 现有能力验收。 |
| PLAY-04 | 全屏与画中画 | 只验证终端支持的能力。Web 画中画跨页不中断；点击站内关闭按钮不跳转。与 Infuse 做对照时单独列出平台差异。 |
| PLAY-05 | 桌面双层控制条 | 录屏约 `00:02–00:03`：暗色浮动面板在画面底部居中，上排左侧音量、中央播放／暂停及跳转、右侧设置和可用的窗口功能；下排独立进度条和时间读数。Web／Electron 用宽窄窗口验收：主操作保持突出，次级功能不会挡住时间轴，不展示不可用或含义未确认的按钮。 |

录屏可见高级选项、倍速和音量增强，但未操作这些功能，不因此要求各端新增；尤其不恢复 Android TV 已移除的倍速按钮。上一项／下一项与跳转秒数、控制条的唤出方式及自动隐藏时间、TV 遥控键映射均待确认；不从桌面鼠标行为推定移动端或 TV 的输入规则。交付时记录端、输入方式及已验证的时间点，区分 Infuse 观察结果与 Vidday 实测。
